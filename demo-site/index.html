03 / 08 TWO CONNECTION LAYERS

RAG는 '지식'을 다루고,
MCP는 '행동'할 도구를 연결합니다

RAG · KNOWLEDGE
검색 증강 생성

AI가 답변을 생성하기 전에 사내/외부 문서를 조회하여 정확한 근거를 바탕으로 답하게 만드는 방식입니다.

질의 분석 → 임베딩 검색 → 근거 기반 답변
MCP · ACTION
모델 컨텍스트 프로토콜

AI가 텍스트 생성에 그치지 않고, 외부 앱이나 데이터베이스 도구를 직접 실행할 수 있도록 연결하는 표준 규약입니다.

AI 모델 ⇄ MCP 도구 ⇄ 실제 인프라 실행
KNOWLEDGE LANE (지식)
사내 문서 → 임베딩 → 벡터 검색
LLM 판단 & 생성
ACTION LANE (행동)
MCP Client → Tool Server → DB · API 실행

데이터 형식이 다를 때 02

도구가 요구하는 인자 타입과 모델 생성 스키마가 다르면 즉시 에러 복구 프롬프트를 트리거합니다.

권한 범위를 넘어섰을 때 03

단순 조회 권한이 파괴적 수정/삭제 작업으로 이어지지 않도록 실행 전 확인 가드레일이 필수적입니다.
