# AI가 코드를 쓸수록, 개발자는 더 깊이 읽어야 한다

AI 에이전트 개발·협업 능력과 코딩 기본기를 하나의 실무 역량으로 설명하는 인터랙티브 칼럼입니다.

## Experience

- 첫 화면에서 LLM과 AI Agent의 차이, Agent 전체 구성요소를 한 흐름으로 설명
- FIELDNOTE 001을 LEARN → CONNECT → COLLABORATE → READ → VERIFY의 5개 장면으로 구성
- 교육과정의 공통 학습 순서 시각화
- RAG·MCP 연결 구조와 멀티에이전트 작업 흐름을 문제 → 기술 순서로 설명
- 에이전트 권한 범위를 직접 바꿔보는 검증 예시
- FIELDNOTE 002에서 7 Layer AI Stack → 운영 관찰 → 성과 측정 흐름 제공
- 모바일, 키보드 탐색, 모션 감소 설정 지원

## Routes

- `/`: AI Agent의 구조와 개발자의 코드 판독·검증 책임
- `/fieldnotes/agent-operations`: 7 Layer AI Stack, 운영 위험, 성과 측정

## Local development

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

배포용 결과 확인:

```bash
npm run build
```

## Source policy

교육기관의 과정 구성과 기업의 발표 자료를 사실 근거로 사용했습니다. 베스핀글로벌의 프로젝트·에이전트·절감 시간 수치는 기업 자체 발표임을 본문에 명시합니다. Jason Ku 영상은 통계가 아니라 개발자의 관점으로 다룹니다.
